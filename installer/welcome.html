Plugin Playground

An open-source runtime tweak system for macOS Apple Silicon. Intercepts processes via Mach exception ports and ARM64 hardware breakpoints for plugins, introspection, and behavior-modification tweaks.

Includes

bin/fangsCore runtime modifier
bin/grantInitializer for core runtime
Plugin Playground.appGUI for managing tweaks (in /Applications)
tweaks/User-owned directory for tweak bundles
